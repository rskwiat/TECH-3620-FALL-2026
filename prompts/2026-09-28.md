### Context

## Session 2 — habit-tracker auth flow

Adding the client-side auth flow to the `habit-tracker` Expo app (SDK 57): login and signup screens, an authenticated home, and route guards that send unauthenticated users to `/login`, wired to the JWT endpoints from session 1. Per `habit-tracker/AGENTS.md`, the Expo v57.0.0 docs were read first — the flow follows the [protected routes](https://docs.expo.dev/router/advanced/protected/) and [authentication](https://docs.expo.dev/router/advanced/authentication/) guides (`Stack.Protected`, session context, storage hook).
