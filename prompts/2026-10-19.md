## Session 1 — habit detail screen: streaks, best streak, and completed days

### Context

Making the Today list's rendered rows open a detail screen. Per `habit-tracker/AGENTS.md`, the Expo v57.0.0 docs were read first — [Expo Router](https://docs.expo.dev/versions/v57.0.0/sdk/router.md) (`useRouter`, `useLocalSearchParams`, `Stack.Protected`) since this adds a new route and navigation. The `(app)` group is a `NativeTabs` navigator (`src/components/app-tabs.tsx`) where every route is a tab, so the detail route lives at the **root** level in `src/app/habit/[id].tsx` — a root `Stack` screen gets real push/back behavior (plus the Android predictive-back-safe `router.back()`) without needing a tab trigger. It's declared in the root `Stack` inside `Stack.Protected guard={!!session}`, so signed-out users are redirected to login instead of ever reaching it.

The screen renders from `GET /api/habits/:id/history` (the `HabitHistory` client type): `currentStreak`, `longestStreak` (best streak), `totalCompletions`, `goalPerDay`, and `perDay` `{ date, count, goalMet }`. Upfront questions settled the shape: **stats + recent days list** for the "completed habits" section, and **view-only** (no log-completion button) to keep the change focused.

Typed routes are on (`app.json` → `experiments.typedRoutes`), so the running Metro dev server (8081) regenerated `.expo/types/router.d.ts` with `/habit/[id]` once the file existed, and navigation uses the object href form (`router.push({ pathname: '/habit/[id]', params: { id } })`) to stay type-safe.
