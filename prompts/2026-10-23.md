## Session 1 — log habit completions from the habit detail screen

### Context

The detail screen at `src/app/habit/[id].tsx` was view-only, so there was no way to add to a habit's logs from the app. The API already shipped the write path — `POST /api/habits/:id/logs` (`api/src/routes/habits.ts`) records a completion, allowing multiple per day, with optional `completedAt` backfill and `note` — but the client (`src/api.ts`) had no wrapper for it and no screen called it.

Per `habit-tracker/AGENTS.md`, the Expo v57.0.0 docs were read before writing code — [Expo Router](https://docs.expo.dev/versions/v57.0.0/sdk/router.md) for `useFocusEffect`, since the tab screens needed to refetch when they regained focus after a log. Reused the existing `Button` component (`src/components/ui/button.tsx`) and the screens' derived loading/error pattern rather than adding new primitives.

The detail screen gained a **Today** card between the hero card and the stat grid. It reads the newest `perDay` bucket from `GET /api/habits/:id/history` (the API's UTC today), shows `X of Y completions logged` plus a progress bar (primary until the goal is met, then `success` green), and a **Log completion** button that becomes **Log another completion** once the goal is met. Pressing it calls `createHabitLog()` with no body (server timestamps "now"), shows the button's spinner while the request is in flight, and surfaces API errors inline. On success it bumps a `refreshKey`, refetching the same `getHabits` + `getHabitHistory` pair while keeping the current data on screen — so the count, progress bar, streak cards, weekly chart, weekly tracker, and 28-day calendar all update without leaving the screen.

Today, Weekly, and Stats also needed to see the new log. Each now installs a `useFocusEffect` that bumps its `refreshKey` when the tab regains focus, skipping the first focus with a `useRef` so mounting still performs exactly one load. That makes the Today progress/streak summaries and the Weekly/Stats widgets reflect completions logged on the detail screen.
